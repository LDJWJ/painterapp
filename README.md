# Painter App - 이미지 편집기

클립보드에서 이미지를 붙여넣어 바로 편집할 수 있는 웹 기반 이미지 편집기입니다.
별도 설치 없이 브라우저에서 바로 사용할 수 있습니다.

## 주요 기능

| 도구 | 설명 |
|------|------|
| 선택 | 드래그로 영역을 선택합니다 |
| 사각형 | 색상과 두께를 지정해 사각형을 그립니다 |
| 화살표 | 화살표를 그려 특정 위치를 가리킵니다 |
| 모자이크 | 선택 영역에 블록 모자이크를 적용합니다 |
| 삭제 | 선택 영역을 흰색으로 지웁니다 |
| 이동 | 선택한 영역의 픽셀을 드래그해 다른 위치로 옮깁니다 (원래 자리는 흰색) |
| 실행 바 | 영역을 선택하면 그 옆에 떠서 이동 / 잘라내기 / 지우기를 바로 실행합니다 |
| 잘라내기 | 드래그한 높이만큼 가로 한 줄을 통째로 잘라내고, 아래 내용 전체를 위로 당깁니다 |
| 좌클릭 / 우클릭 | 마우스 클릭 아이콘을 이미지에 삽입합니다 |
| 텍스트 | 캔버스에 텍스트를 입력하고 배치합니다 |

## 사용 방법

1. `index.html`을 브라우저에서 엽니다
2. 편집할 이미지를 복사한 뒤 **Ctrl + V** (Mac: **⌘ + V**) 로 붙여넣습니다
3. 도구를 선택하고 캔버스 위에서 드래그하여 편집합니다
4. 완료 후 **다운로드** 또는 **복사** 버튼으로 결과를 저장합니다

## 이미지 확대 / 축소

캔버스에 붙여넣은 이미지를 화면에서 확대하거나 축소할 수 있습니다.
실제 이미지 해상도는 유지되며, 화면 표시만 변경됩니다.

| 방법 | 동작 |
|------|------|
| 툴바 `＋` 버튼 | 확대 |
| 툴바 `－` 버튼 | 축소 |
| 툴바 `크기` 버튼 | 100%로 초기화 |
| `Ctrl / ⌘` + 마우스 휠 | 스크롤로 확대/축소 |
| 키보드 단축키 | 위 단축키 표 참조 |

## 빈 줄 없애기 (선택 → 바로 실행)

스크린샷에서 필요 없는 한 줄을 빼고 아래 내용을 위로 붙이고 싶을 때 사용합니다.

**선택 → 실행 바**가 기본 흐름입니다. `선택` 도구로 영역을 드래그하면 선택 영역 옆에 실행 바가 떠서,
같은 선택을 그대로 이동 / 잘라내기 / 지우기로 이어갈 수 있습니다.

| 실행 바 버튼 | 동작 | 단축키 |
|---|---|---|
| ✥ 이동 | 이동 도구로 전환 (선택 유지) → 선택 영역 안쪽을 드래그해 옮김 | - |
| ↥ 선택 폭 당기기 | **선택한 폭 안에서만** 잘라내고 그 열의 아래 내용을 위로 당김 (이미지 크기 유지) | `Alt + Delete` |
| ✂ 줄 전체 당기기 | 가로 한 줄 전체를 잘라내고 아래 전체를 위로 당김 (이미지 높이 감소) | `Shift + Delete` |
| ⌫ 지우기 | 선택 영역을 흰색으로 지움 (위치·크기 그대로) | `Delete` |

`Esc` 로 선택을 해제합니다.

도구를 직접 써도 됩니다.

- **잘라내기(✂) 도구**: 없앨 구간을 위에서 아래로 드래그하면 그 높이만큼 가로 한 줄이 잘리고 아래가 위로 올라옵니다.
- **이동(✥) 도구**: 옮길 영역을 드래그해 선택한 뒤, 선택 영역 안쪽을 다시 드래그하면 그 부분이 통째로 따라옵니다 (원래 자리는 흰색).

선택 → 이동 → 잘라내기 도구끼리 전환할 때는 선택 영역이 그대로 유지됩니다.

## 텍스트 도구

텍스트 도구 선택 시 상단에 서식 바가 표시됩니다.

- **글꼴**: Pretendard, Noto Sans KR, 맑은 고딕, 굴림, Arial 등
- **크기**: 8px ~ 200px
- **서식**: 굵게 / 기울기 / 밑줄
- **정렬**: 왼쪽 / 가운데 / 오른쪽
- 텍스트 클릭 후 드래그로 위치 이동 가능
- `Delete` 키로 선택한 텍스트 삭제

## 옵션

- **색상**: 색상 피커 또는 프리셋(빨강, 파랑, 초록, 검정) 선택
- **두께**: 선 굵기 조절 (1px ~ 10px)
- **블록 크기**: 모자이크 블록 크기 조절 (10px ~ 30px)
